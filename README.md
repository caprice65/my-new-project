# practce

Godot 4 practice workspace.

## Project

| Path | Description |
|------|-------------|
| [`dodge_the_creeps/`](dodge_the_creeps/) | Dodge the Creeps (Godot **4.7**, GDScript) |

Open **`dodge_the_creeps/project.godot`** in Godot (do not open the repo root as a Godot project).

## Quick start

1. Install Godot 4.7+
2. Godot → Import → select `dodge_the_creeps/project.godot`
3. Press Play (`F5`); main scene is `scenes/main.tscn`

## Repo notes

- Ignore `.godot/` (editor cache); keep `*.uid` and `*.import`
- IDE: workspace points at this folder; Godot project lives one level down in `dodge_the_creeps/`
